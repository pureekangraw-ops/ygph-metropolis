# LIGHTHOUSE APK Foundation Proof Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce an isolated Capacitor Android Debug APK proof for LIGHTHOUSE and publish it as a GitHub Actions artifact.

**Architecture:** Keep all app-shell code under `android-shell/`; generate the native Android project only in CI. A dedicated Actions workflow verifies the shell contract, runs Capacitor generation/sync, runs Gradle `assembleDebug`, and uploads the APK.

**Tech Stack:** Node.js 22, Capacitor 8.5.0, Android/Gradle generated by Capacitor, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-30-lighthouse-apk-foundation-proof-design.md`

## Global Constraints
- Package ID is exactly `com.yggdrasil.lighthouse`.
- Work is isolated from PR #84 Intent/Multi-Group/Runtime files.
- No location features, maps, external service keys, deployment, or store publishing.
- Debug APK is the only native deliverable in this phase.
